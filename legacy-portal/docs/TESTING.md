# Verification checklist
Automated: JS syntax, ES module path existence, HTML asset references, domain module smoke tests, ZIP integrity. Browser rendering, accessibility, import flows and cross-browser persistence still require manual testing.

Manual: launch with HTTP; add business; edit; filter; reject duplicate; score; create campaign; add prospect; update status/follow-up; generate/export brief; export backup; import backup; refresh and verify persistence; check mobile width; clear data only after backup.
